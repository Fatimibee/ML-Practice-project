# ML-Practice-Projects

A collection of machine learning projects developed for practice and learning, covering a range of algorithms and real-world datasets.

## Projects Included

- **Student Performance Prediction**  
  Uses **Linear Regression** to predict students' academic performance based on features like study time and attendance.

- **Iris Flower Classification (Logistic Regression)**  
  Classifies iris species as *Versicolor* or *Virginica* using **Logistic Regression**.

- **Spam Detection**  
  Implements a **Naive Bayes** model to classify messages as spam or not. Dataset sourced from **Kaggle**.

- **Iris Prediction using KNN**  
  Uses the **K-Nearest Neighbors (KNN)** algorithm for iris species classification.

- **Loan Approval Prediction(Web App)**  
  Predicts whether a loan application will be approved using the **Random Forest Classifier**. Based on applicant data such as income, credit history, and loan amount.

- **Internship Fraud Detection (Web App)**  
  A **Streamlit-based** web application that predicts whether an internship listing is real or fake.  
  - Model: **Complement Naive Bayes**  
  - **RandomOverSampler** used to handle class imbalance  
  - Real internship data scraped from **Internshala**  
  - Fake internship data taken from a **Kaggle dataset**
